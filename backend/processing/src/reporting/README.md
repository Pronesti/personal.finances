# Private backend analytical routines

These deterministic read-only algorithms were ported from the committed Tarjetas reference into the backend artifact. They have no browser runtime, SQL adapter, Next.js dependency, environment loader, reference-directory lookup or posting capability. Their inputs are values explicitly supplied by Laravel. PHP constructs the repeatable-read owner-qualified PostgreSQL snapshot, validates native cents and scope, and reads validated reference tables. The helper runs through the same credential-filtering, bounded private-process supervisor as extraction.

The ES modules are target-owned source. They were initially transpiled from the reference's pure TypeScript functions to remove historical type-only database/server dependencies. Maintain these modules here; builds do not read `web/` or `frontend/`. The rate modules are pure; filesystem loaders were removed. The localization resource is an independent backend copy of the frozen dictionaries. `../reports.ts` exposes the production projections and a non-HTTP acceptance projection without embedding fixture facts or expected results. `../../build.mjs` verifies the independent build graph.

The guarded PHP acceptance adapter is `backend/tests/Support/report-adapter.php`; it accepts the portable input plus a `supermarket` object via stdin and returns actual projections via stdout. Compare its output using the frozen `docs/rebuild/check-rebuild-results.py`. The projection test checks all 3,239 leaves (2,199 numeric). This pure comparison is separate from PostgreSQL snapshot, API and browser acceptance. No analytical helper output is admitted as a financial command.
